VOCABULARY JOURNAL BY RANDYAA - paket aplikasi Android (PWA)

Isi: index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png
Semua file harus berada di folder yang sama.

CARA PASANG DI ANDROID
1. Unggah semua file ke hosting HTTPS gratis, misalnya:
   - Netlify Drop (app.netlify.com/drop): seret folder ini ke halaman itu.
   - GitHub Pages: unggah file ke repositori, aktifkan Pages.
   - Cloudflare Pages.
2. Buka alamat hasilnya di Chrome Android.
3. Menu tiga titik > "Instal aplikasi" (atau "Tambahkan ke layar utama").
4. Buka dari ikon di layar utama. Di tab Saya, ketuk "Izinkan" pada Notifikasi sistem.

CATATAN NOTIFIKASI
- Pengingat di dalam aplikasi selalu muncul di Beranda saat jam pengingat lewat dan kamu belum belajar.
- Notifikasi sistem muncul saat aplikasi terbuka atau berjalan di latar.
- Notifikasi saat aplikasi tertutup bergantung pada Chrome (Periodic Background Sync). Chrome hanya
  mengizinkannya untuk aplikasi terpasang yang sering dipakai, dan waktunya tidak presisi.
  Untuk pengingat yang pasti tepat waktu, tambahkan juga alarm di aplikasi jam ponsel.

DATA
Semua data tersimpan di browser perangkat. Pakai tab Saya > Cadangan data untuk menyalin dan memulihkan.
Menghapus data situs Chrome juga menghapus database kata.

FORMAT IMPOR
Kata|Arti|Contoh kalimat   (satu baris per entri; baris berawalan # diabaikan)
